# JoJo no Kimyou na Bouken: Infinity Universe

## English
A fan-made fighting game based on JoJo's Bizarre Adventure, built with the IKEMEN GO engine.
Features characters from all JoJo parts, online play support, and custom screenpack.

**How to play:**
1. Download the game from the link below
2. Extract the ZIP file
3. Run "INFINITE UNIVERSE.exe"
4. Enjoy!

Download: https://mega.nz/folder/XWZVCLRK#pgX52VFVcosUMlN1uCCxTA
